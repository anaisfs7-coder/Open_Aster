Matriz comparativa

Cruza dos dimensiones del estándar. Cada celda cuenta las soluciones (o empresas) que cumplen ambas; una solución puede aparecer en más de una fila si toca varias áreas, KPIs o tecnologías. Haz clic en una celda para ver cuáles son.

Cómo se construye el estándar

Los textos de cada ficha vienen escritos de forma distinta por cada empresa. Para compararlas, cada solución se clasifica en las mismas listas cerradas a partir de sus propios campos.
